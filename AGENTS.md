# Website working rules

## Never publish
- Never publish credentials, tokens, private keys, hidden configuration, private correspondence, or unrelated local files.
- Never invent CV facts or publish placeholder social URLs as real links.
- Never push to GitHub, deploy, or otherwise publish this site without the user's explicit authorization. Current work is local only.
- Do not expose sensitive identifiers, home addresses, or private contact details publicly without explicit approval. Keep CV content local for review first.

## Ask first
- Ask before public deployment, pushing commits, adding analytics or third-party data collection, or sharing files with external services.
- Ask before removing existing user content, changing CV facts, or omitting CV sections from the finished page.
- Flag sensitive CV content for review before any later publication.

## Style and content
- Use a professional, approachable voice, Columbia blue accents, readable typography, and streamlined navigation.
- Include the CV's information in its original section order; preserve factual wording, dates, and names.
- Build responsive, accessible HTML with semantic sections, visible keyboard focus, and good color contrast.
- Prefer lightweight local assets and no unnecessary dependencies or tracking.
- Verify content and local links; report verification limits and list every created file.
